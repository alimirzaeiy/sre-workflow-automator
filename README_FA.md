# سامانه جامع اتوماسیون استقرار (Deploy Automation Platform)

راهکار جامع، سازمانی و متن‌باز برای تیم‌های DevOps و SRE جهت اتوماسیون فرآیندهای ممیزی الزامات پیش از استقرار، صف تسک‌های ClickUp، خودکارسازی Reverse Proxy با Nginx و SSL Certbot، ساخت و مدیریت پایگاه‌داده PostgreSQL و تولید خط لوله CI/CD در GitLab به همراه بات تعاملی تلگرام و داشبورد وب زنده.

---

## 🎯 امکانات کلیدی

### ۱. پردازش صف تسک‌های ClickUp و تشخیص خودکار مرحله (State Resumption)
- استعلام خودکار تسک‌های با وضعیت `new`، `in progress` و `waiting for customer` (مرتب‌شده از قدیمی‌ترین به جدیدترین).
- تحلیل هوشمند وضعیت تسک و پیشنهاد یکی از ۶ مرحله استقرار:
  1. `دسترسی دارم` (Maintainer Access Granted)
  2. `الزامات دیپلوی رعایت شده` (Deploy Readiness Passed)
  3. `فایل .gitlab-ci نوشته شده` (GitLab CI Deploy Jobs)
  4. `فایل docker compose نوشته شده` (Docker Compose Created)
  5. `env ها و دیتابیس و log ship انجام شده` (Envs, Database, Log Shipping Done)
  6. `دیپلوی تست شده` (Deploy Tested / Completed)
- امکان تایید پیشنهاد سیستم یا انتخاب دستی مرحله دلخواه توسط کاربر و ادامه دیپلوی از همان نقطه.

### ۲. ممیزی هوشمند و سفارشی الزامات استقرار (پشتیبانی از هوش مصنوعی)
امکان سنجش خودکار پروژه‌ها و مخازن کد با استانداردهای سازمانی دلخواه پیش از استقرار:
- **امکان شخصی‌سازی کامل الزامات و چک‌لیست‌ها**: هر سازمان می‌تواند چک‌لیست الزامات مد نظر خود را (مانند مستندات معماری، ساختار برنچ‌ها، اندپوینت سلامت و متریک‌ها، مراحل CI/CD، ابزارهای کیفیت کد و تست و پیکربندی متغیرها) تنظیم نماید.
- **بررسی هوشمند با هوش مصنوعی یا موتور قوانین**: در این پلتفرم می‌توانید متنی از مواردی که نیاز است از سمت توسعه‌دهنده در پروژه رعایت شده باشد را در پرامپت یا تنظیمات سیستم قرار دهید تا هوش مصنوعی مخزن را مطابق با آن ارزیابی و ممیزی کند.
- **تولید خودکار پیش‌نویس کامنت و بازخورد به توسعه‌دهنده**: در صورت وجود هرگونه نقص، هوش مصنوعی کامنتی مؤدبانه و دقیق با ذکر راهکارهای اصلاحی به زبان فارسی تولید کرده و پس از تأیید در کلیک‌آپ ارسال و وضعیت تسک را به `waiting for customer` تغییر می‌دهد.

### ۳. خودکارسازی Reverse Proxy با Nginx و گواهی SSL (Certbot)
- پشتیبانی از حالت دیمن سیستمی (`/etc/nginx/sites-available`) و کانتینر داکر در `/srv`.
- دریافت گواهی SSL با Certbot به دو روش **HTTP-01 Challenge** و **DNS-01 Challenge**.
- پشتیبانی از Path Routing و اتصال خودکار به `http://{server_ip}:{port}`.
- اعتبارسنجی کانفیگ با `nginx -t` و بارگذاری مجدد (Reload).

### ۴. خودکارسازی پایگاه‌داده PostgreSQL
- ساخت خودکار دیتابیس، کاربر مجزا و کلمه عبور امن.
- ویرایش خودکار فایل `pg_hba.conf` جهت اضافه کردن دسترسی IP سرورهای اپلیکیشن به همراه بازنشانی تنظیمات (`pg_reload_conf`).
- تولید و ارائه Connection DSN جهت استفاده در فایل‌های محیطی (`.env`).

### ۵. بات هوشمند تلگرام و تخصیص وظایف تیم SRE
- رصد دائمی تسک‌های جدید و ارسال نوتیفیکیشن تفکیک‌شده به تاپیک اختصاصی اعضا در سوپرگروه تلگرام (`message_thread_id`).
- تخصیص هوشمند بر مبنای بار کاری با استفاده از موتور قوانین معین (Rule Engine) یا هوش مصنوعی (OpenAI / Anthropic / Ollama).
- مدیریت امن توکن موقت گیت‌لب در RAM و پاک‌سازی خودکار.
- دکمه‌های شیشه‌ای تعاملی برای پذیرش استقرار، درخواست دسترسی، یا ثبت گزارش ایرادات.

### ۶. داشبورد شیشه‌ای مانیتورینگ و آنالیتیکس SRE (Liquid Glass Dashboard)
- دسترسی بلادرنگ تحت وب روی پورت ۸۰۸۵ (`http://localhost:8085/dashboard`).
- **تب تسک‌های من:** گروه‌بندی وضعیت‌ها با اولویت‌بندی هوشمند توسط هوش مصنوعی.
- **تب فرم‌های SRE:** مشاهده تمامی فرم‌های ورودی تیم با فیلتر سریع.
- **آنالیتیکس و نمودارهای عملکردی:**
  - نمودار دونات سهم تسک‌های باز اعضا.
  - میانگین زمان توقف در وضعیت New بر حسب نوع فرم.
  - نمودار توان عملیاتی هفتگی (Weekly Throughput).
  - **هیتمپ فعالیت تیم (مشابه GitLab Contribution Matrix):** ماتریس ۳۷۱ روزه (۵۳ هفته) به تفکیک اعضا با تقویم خورشیدی/میلادی.

## 🚀 نحوه اجرا

```bash
# نصب وابستگی‌ها
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# اجرای سرویس اصلی
python3 -m deploy_automation.main
```

### اجرای ابزار تعاملی ترمینال (CLI)
```bash
python3 -m deploy_automation.cli
```

### اجرای کانتینری با داکر
```bash
docker compose up -d --build
```
